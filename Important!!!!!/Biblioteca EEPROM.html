Biblioteca EEPROM

La memoria de datos EEPROM está disponible con varias MCU PIC. mikroBasic PRO for PIC incluye biblioteca para trabajar cómodamente con EEPROM .

Rutinas de biblioteca

  • EEPROM_Leer
  • EEPROM_Escritura

EEPROM_Leer

Prototipo

// para la subfunción
PIC16 EEPROM_Read ( dirección dim como byte ) como byte

// para la subfunción
PIC18 EEPROM_Read ( dirección dim como palabra ) como byte
Devoluciones

Devuelve el byte de la dirección especificada.
Descripción

Lee datadesde especificado address. El parámetro addressdepende de MCU; para la familia PIC16 es de tipo byte y para la familia PIC18 es de tipo palabra. Para MCU PIC18 con más ubicaciones de datos EEPROM , es responsabilidad del programador configurar el registro SFR EEADRH de manera adecuada.
Requiere

Requiere módulo EEPROM .

Asegure un retraso mínimo de 20 ms entre el uso sucesivo de rutinas EEPROM_Writey EEPROM_Read. Aunque PIC escribirá el valor correcto, EEPROM_Readpodría devolver un resultado indefinido.
Ejemplo 
tmp = EEPROM_Read ($3F)

EEPROM_Escritura

Prototipo

// para el
subprocedimiento PIC16 EEPROM_Write( dim Dirección como byte , dim Datos como byte )

// para el
subprocedimiento PIC18 EEPROM_Write( dirección dim como palabra , datos dim como byte )

Devoluciones

Nada.
Descripción

Escribe dataen especificado address. El parámetro addressdepende de MCU; para la familia PIC16 es de tipo byte y para la familia PIC18 es de tipo palabra. Para MCU PIC18 con más ubicaciones de datos EEPROM , es responsabilidad del programador configurar el registro SFR EEADRH de manera adecuada.

Tenga en cuenta que todas las interrupciones se desactivarán durante la ejecución de la EEPROM_Writerutina (se borrará el bit GIE del registro INTCON). La rutina establecerá este bit al salir.
Requiere

Requiere módulo EEPROM .

Asegure un retraso mínimo de 20 ms entre el uso sucesivo de rutinas EEPROM_Writey EEPROM_Read. Aunque PIC escribirá el valor correcto, EEPROM_Readpodría devolver un resultado indefinido.
Ejemplo 
EEPROM_Escribir ($32, $AA)

Ejemplo de biblioteca

El ejemplo escribe valores en 20 ubicaciones sucesivas de EEPROM . Luego, lee los datos escritos e imprime en PORTB para una verificación visual.

Copiar código al portapapeles 
programa EEPROM

dim contador como byte                      'variable de bucle

principal:
  ANSEL = 0                             ' Configurar pines AN como E/S digital
  ANSEL = 0
  C1ON_bit = 0                           ' Deshabilitar comparadores
  C2ON_bit = 0

  PUERTOB = 0
  PUERTO = 0
  PUERTO = 0

  TRIB = 0
  TRISCO = 0
  TRISD = 0
   
  para contador = 0 a 31                  ' Llena el búfer de datos 
    EEPROM_Write(0x80+contador, contador) ' Escribe datos en la dirección 0x80+ii 
  siguiente contador

  EEPROM_Write(0x02,0xAA)                ' Escribe algunos datos en la dirección 2 
  EEPROM_Write(0x50,0x55)                ' Escribe algunos datos en la dirección 0150

  Delay_ms(1000)                         ' Parpadean los diodos PORTB y PORTC 
  PORTB = 0xFF                           ' para indicar el inicio de la lectura
  PUERTO = 0xFF
  Retardo_ms(1000)
  PUERTOB = 0x00
  PUERTO = 0x00
  Retardo_ms(1000)

  PORTB = EEPROM_Read(0x02)              ' Leer datos de la dirección 2 y mostrarlos en PORTB 
  PORTC = EEPROM_Read(0x50)              ' Leer datos de la dirección 0x50 y mostrarlos en PORTC

  Retardo_ms(1000)
  
  for counter = 0 to 31                  ' Leer bloque de 32 bytes desde la dirección 0x100 
    PORTD = EEPROM_Read(0x80+counter)    ' y mostrar datos en PORTC
    Retardo_ms(100)
  siguiente extremo del contador
